# reestar_frontend_page

Reestar – Restaurant Landing Page:

Reestar is a simple and clean restaurant landing page built using pure HTML and CSS.
It showcases a set of food items with images, descriptions, and an order button (UI only).
The page also includes a basic Contact Us form layout to practice form styling and table-based alignment.

This project is created as a beginner front-end practice to explore layout design, card styling, image handling, and basic UI components.

Features:

Food cards with images and descriptions

Clean and structured layout

Simple navigation header

Static “Order Now” buttons (non-functional)

Contact form section styled with basic CSS

Fully front-end (HTML & CSS only)

Technologies Used:

HTML5

CSS3

Purpose:

This project is mainly for learning and improving:

Webpage layout design

CSS selectors & styling

Responsive image handling

Basic front-end structure
